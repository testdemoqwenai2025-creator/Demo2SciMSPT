Getting Started

Quick Start Guide

Get up and running with SciMSPT APIs in under 5 minutes. Follow these steps to make your first API call and start building tomorrow's scientific applications.

Create Your API Key
Sign up for a free developer account at portal.scimspt.dev to receive your unique API key. Free tier includes 1,000 requests/month with access to all endpoints.
Install the SDK
Choose your preferred language and install our official SDK. We support Python, JavaScript/TypeScript, Go, Rust, and Java. Each SDK includes type definitions, retry logic, and automatic pagination.
Make Your First Request
Use your API key to authenticate requests. The example below fetches trending research papers from the past week, filtered by AI/ML domain with venture potential scoring enabled.
Build & Scale
Explore our full API reference, set up webhooks for real-time updates, and integrate with your existing pipelines. Our enterprise tier offers dedicated infrastructure and custom rate limits.
Python • First Request 
from scimspt import SciMSPTClient

# Initialize client with your API key
client = SciMSPTClient(
    api_key="sk_live_your_api_key_here",
    environment="production"  # or "sandbox" for testing
)

# Fetch trending papers with venture scoring
response = client.papers.search(
    domains=["ai", "machine-learning"],
    date_range="last_week",
    include_venture_score=True,
    limit=20
)

# Access results with rich metadata
for paper in response.papers:
    print(f"📄 {paper.title}")
    print(f"   Venture Score: {paper.venture_score}/100")
    print(f"   Fundable Domains: {paper.fundable_domains}")
Security

All API requests require authentication using Bearer tokens. API keys can be generated and managed from your developer dashboard.

Simple Bearer token authentication. Include your key in the Authorization header for every request.

Keys expire after 90 days of inactivity. Automatic rotation available for enterprise accounts.

Go • go get 
// Install via go get
go get github.com/scimspt/scimspt-go

package main

import (
    "context"
    "fmt"
    "github.com/scimspt/scimspt-go"
)

func main() {
    // Create client with API key
    client := scimspt.NewClient(
        scimspt.WithAPIKey("sk_live_..."),
        scimspt.WithEnvironment(scimspt.Production),
    )
    
    // Context-aware requests
    ctx := context.Background()
    resp, err := client.Papers.Search(ctx, &scimspt.PaperSearchRequest{
        Domains: []string{"materials-science"},
        Limit:   25,
    })
    
    if err != nil {
        panic(err)
    }
    
    for _, paper := range resp.Papers {
        fmt.Printf("%s (Score: %d)\n", paper.Title, paper.VentureScore)
    }
}
Rust • cargo 
// Add to Cargo.toml
[dependencies]
scimspt = "0.4.0"
tokio = { version = "1.0", features = ["full"] }

use scimspt::{Client, PaperSearchRequest};
use scimspt::config::{Environment, ClientConfig};

#[tokio::main]
async fn main() -> Result<(), Box> {
    // Configure client with async runtime
    let config = ClientConfig::new()
        .with_api_key("sk_live_..."?)
        .with_environment(Environment::Production);
    
    let client = Client::new(config);
    
    // Type-safe request building
    let request = PaperSearchRequest::builder()
        .domains(vec!["neuroscience".to_string()])
        .include_venture_score(true)
        .limit(30)
        .build();
    
    let response = client.papers().search(request).await;
    
    for paper in response.papers() {
        println("📄 {} [{}]", paper.title(), paper.venture_score());
    }
    
    Ok(())
}
API Reference

Papers API

Access millions of research papers from arXiv, bioRxiv, medRxiv, chemRxiv, and ScienceDaily. Filter by domain, date, venue, and compute venture potential scores.

GET
/v2/papers/search
Search across all integrated preprint servers and journals. Returns ranked results with metadata, abstracts, and venture scoring.
query string Free-text search query (supports boolean operators)
domains[] string[] Filter by domain: ai, biotech, quantum, materials, neuroscience, climate
date_from date Start date filter (ISO 8601 format)
include_scores boolean Include venture potential scores (default: false)
limit integer Results per page (1-100, default: 20)
GET
/v2/papers/{doi}
Retrieve detailed information about a specific paper using its DOI identifier.
doi path Digital Object Identifier (e.g., 10.48550/arXiv.2312.00123)
include_citations boolean Include citation network data
include_related boolean Include related papers and similar work
GET
/v2/papers/trending
Get currently trending papers based on citations, social mentions, and venture activity signals.
window string Time window: 24h, 7d, 30d, 90d
category string Category filter (optional)

Real-time Data

RSS Feeds & Webhooks

Stay updated with automated feeds from ScienceDaily, arXiv, bioRxiv, and more. Set up webhooks for real-time notifications when new papers match your criteria.

Python • RSS Feed Parser 
from scimspt.feeds import ScienceDailyParser, FeedConfig

# Configure feed monitoring
config = FeedConfig(
    domains=["ai", "biotech", "quantum"],
    min_venture_score=70,
    notify_on_new=True,
    webhook_url="https://your-app.com/webhook/scimspt"
)

# Initialize parser with auto-classification
parser = ScienceDailyParser(config=config)

# Parse latest feed and classify articles
digest = parser.parse_latest()

# Access classified articles by domain
for article in digest.articles:
    print(f"[{article.domain}] {article.title}")
    print(f"   Potential: {article.venture_potential}/100")
    print(f"   URL: {article.url}")
