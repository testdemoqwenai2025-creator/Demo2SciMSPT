Particle Physics Analyzer
Trained on CERN Open Data

Deep learning model for automated particle event classification and anomaly detection in LHC collision events. Capable of identifying Higgs boson decays, exotic particle candidates, and rare processes with 97.3% accuracy.

Event Classification Anomaly Detection Higgs Analysis Jet Tagging

Spectral Data Processor
Trained on JWST/NIRSpec Data

Advanced neural network for processing JWST spectroscopic data. Automatically identifies chemical compositions, redshift measurements, and atmospheric properties of exoplanets and distant galaxies.

Redshift Estimation Chem ID Atmosphere Model Line Fitting

Gravitational Wave Finder
Trained on LIGO/Virgo/KAGRA Data

Convolutional neural network optimized for detecting gravitational wave signals from binary black hole mergers, neutron star collisions, and cosmic string signatures in noisy detector data.

BBH Detection BNS Merger Signal Denoising Parameter Estimation

Exoplanet Characterizer
Trained on TESS/Kepler Archives

Machine learning pipeline for identifying and characterizing exoplanets from transit photometry data. Predicts planetary radius, orbital parameters, and habitability scores.

Transit Detection Radius Prediction Habitable Zone False Positive Filter
